# meme-board

世界のミームコイン関連ニュースと市場データを、複数の公開情報源からそのまま集約して並べるだけのサイト。CoinLife(`../web`, `../program`)とはアカウント・DB・機能とも一切共有しない、独立した単体アプリです。

## コンセプト

- 当サイト自身は分析・予想・売買推奨を行いません。掲載記事の選定・要約・意見付けも行いません。
- 「今後の予想として報じられている記事」欄は、出典記事自体が predict / forecast などの語で予想を書いている記事を機械的に振り分けているだけで、当サイトの見解ではありません。
- 判断は常に閲覧者自身が、複数の情報源を見比べた上で行うことを前提としています。
- 分類ロジック・情報源一覧はすべて `/sources` ページで公開しています。

## 使っているデータ

- ニュース: CoinDesk / Cointelegraph / Decrypt / CryptoSlate / NewsBTC / Bitcoin.com News の公開RSSフィード(`lib/feeds.ts`)
- 市場データ: CoinGecko公開API(ミームコインカテゴリ、`lib/market.ts`)。いずれも登録・APIキー不要。

トップページは15分ごとに再検証(ISR)され、DBやログイン機能は持ちません。

## セットアップ

```bash
npm install
npm run dev
```

## デプロイ

DB不要・環境変数不要の単純なNext.jsアプリなので、Vercel等にこのディレクトリをルートとしてデプロイするだけで動作します。
