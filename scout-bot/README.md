# Memecoin Scout (通知のみ・半自動)

X(Twitter)上でまだ広く知られていないミームコインの初動を検出し、**通知するだけ**のツール。
**自動発注・自動売買は一切行わない。** 判断と発注は常に人間が行う。

CoinLife本体(`../web`, `../program`)とは独立したプロジェクト。CoinLifeは「資金を預からない」設計方針を取っているため、そこに自動売買機能を混ぜないための分離。

## できること / できないこと

- できる: X検索 → 新規ティッカー抽出 → オンチェーン検証 → 組織的シリング/bot連投の検知 → トラクションスコアリング → レポート通知
- できない: 発注、ウォレット操作、資金の移動。ソースコード上にも発注ロジックは存在しない。

## セットアップ

```bash
cd scout-bot
npm install
cp .env.example .env
```

`.env` の `SIGNAL_PROVIDER` は初期値 `mock`。この状態でAPIキー無しにパイプライン全体(検証・スコアリング・レポート整形)を確認できる:

```bash
npm run scan
```

## 本番のXデータを使うには

`.env` を編集:

```
SIGNAL_PROVIDER=x
X_BEARER_TOKEN=<X Developer PortalでBasic以上のプランを契約して取得したBearer Token>
```

**注意**: 公式X API以外(スクレイピング、非公式ライブラリ)は規約違反・アカウントBANのリスクがあるため意図的に採用していない。代替データソース(例: crypto向けソーシャル分析API)を追加したい場合は `src/providers/` に `SignalProvider` インターフェースを実装したファイルを追加し、`src/providers/index.ts` に登録する。

## チェーンとRPC

`.env` の `SCAN_CHAINS` で対象チェーンを指定。各チェーンの `*_RPC_URL` が未設定の場合、そのチェーンのコントラクトは常に「未検証」として報告される(アドレスを推測・捏造することはしない)。`ROBINHOOD_RPC_URL` は本稿執筆時点で公開RPCが未確定のため空欄がデフォルト。

Solanaはさらに pump.fun の公開API(非公式、`PUMPFUN_API_BASE`)で name/symbol を補完する。

## 通知

デフォルトはコンソール出力のみ。`NOTIFY_WEBHOOK_URL` を設定するとDiscord/Slack/汎用Webhookにも送信する(`NOTIFY_WEBHOOK_KIND` で形式を切り替え)。

## 常時実行

```bash
npm run watch
```

`WATCH_INTERVAL_MINUTES` 間隔でスキャンを繰り返す(デフォルト15分)。

## 設計上の安全策

- **新規ティッカーのみ**: 一度検出したティッカーは14日間再検出しない(`src/analysis/dedupe.ts`)
- **独立アカウント3件未満は報告しない**: bot 1体の連投だけでは候補に上げない
- **コントラクトアドレスは投稿本文からのみ抽出し、必ずRPC/エクスプローラーで検証**。リプライ欄の自己申告アドレスをそのまま信用しない
- **組織的シリングの疑いがあるものはスコアを強制的に下げる**(`src/analysis/coordination.ts`, `src/analysis/scoring.ts`)
- **情報源とタイムスタンプを全項目に添付**、本文から根拠を取れない場合は「不明」「要確認」と明記し、推測で埋めない

## 免責

ミームコインは詐欺・ラグプルが極めて多い高リスク資産。このツールはあくまで「初動の検出」を補助するもので、投資助言ではない。表示された情報は必ず自分で一次情報(公式ローンチページ、オンチェーンデータ)を確認すること。
