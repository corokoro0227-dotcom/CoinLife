# BTC先物 押し目買いシグナルスキャナー

単一取引所のBTC無期限先物(デフォルトは `BTC/USDT:USDT` on MEXC)を常時監視し、以下の条件がすべて揃ったときにDiscord/Telegramへ通知するbotです。

## 戦略

「売られすぎ+出来高急増」だけでは、下落の途中(悲鳴/清算カスケード)を拾ってしまうリスクがあります。そこで、**上位足のトレンドに逆らわない押し目買いセットアップ**に絞り込む設計にしています。

1. **トレンドフィルタ(地合い)**: 上位足(デフォルト4h)のEMA(200)を計算し、実行足の終値がこのEMAより **上** にあるときだけシグナルを有効にする。強い下降トレンド中の逆張り("落ちてくるナイフを掴む")を避け、上昇トレンド/レンジ相場での押し目に限定する。
2. **売られすぎ(実行足、デフォルト15m)**: RSI(14)が **30未満**。短期的な過熱の反対側(下げすぎ)を検出する。
3. **出来高スパイク**: 直近確定足の出来高が、直前20本平均の **+200%以上(3倍以上)**。何かしらの強い売買が入ったことを裏付ける。
4. **反転確認**: シグナルが出た確定足自体が **陽線(close > open)** で閉じていること。「まだ下げている最中」ではなく「その足の中ですでに買いが優勢になった」ことを確認する(追加のAPI呼び出し不要、同じ確定足のデータで判定できるためラグなし)。

4条件がすべて揃った場合のみアラートを送ります。取引所は単一(BTCは裁定で価格がほぼ同期するため、複数取引所を跨いでも独立したシグナルにはなりにくいという判断)。

### この戦略の位置づけと限界

- あくまで**押し目買いの候補を絞り込むアラートツール**であり、自動発注は行いません。エントリー/損切り/利確は自分で判断してください。
- トレンドフィルタは「強い下降トレンド中の逆張りを避ける」ためのものであって、上昇トレンド中の押し目が必ず反発することを保証するものではありません。
- ファンディングレートや建玉(OI)などの先物特有の指標は見ていません。特にショートスクイーズが絡む場面ではこれらを併用すると精度が上がります。
- 実運用前に、過去データでのバックテスト(勝率・期待値の確認)を強く推奨します。

## セットアップ

```bash
cd bots/rsi-volume-scanner
npm install
cp .env.example .env
# .env を編集(取引所・通知先など)
npm run dev
```

本番運用では `npm run build && npm run start:dist`、または pm2 / systemd / Docker などで常駐させてください。

## 設定(`.env`)

`.env.example` を参照。主な項目:

| 変数 | 説明 | デフォルト |
|---|---|---|
| `EXCHANGE` | ccxtの取引所ID(単一) | `mexc` |
| `SYMBOL` | ccxt統一シンボル | `BTC/USDT:USDT` |
| `TIMEFRAME` | エントリー判定に使う実行足 | `15m` |
| `RSI_PERIOD` / `RSI_THRESHOLD` | RSI期間・しきい値 | `14` / `30` |
| `VOLUME_LOOKBACK` | 出来高平均の対象本数 | `20` |
| `VOLUME_SPIKE_MULTIPLIER` | 出来高倍率のしきい値(3.0 = +200%) | `3.0` |
| `REQUIRE_BULLISH_CLOSE` | シグナル足が陽線であることを必須にするか | `true` |
| `TREND_TIMEFRAME` / `TREND_EMA_PERIOD` | トレンドフィルタに使う上位足・EMA期間 | `4h` / `200` |
| `POLL_INTERVAL_SEC` | ポーリング間隔(秒) | `60` |
| `ALERT_COOLDOWN_SEC` | 再通知の最小間隔(秒) | `3600` |
| `DISCORD_WEBHOOK_URL` | Discord通知先 | 任意 |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | Telegram通知先 | 任意 |

通知先を何も設定しない場合はコンソールログのみに出力されます。

## 仕組み(実装メモ)

- `evaluateExchange`(`src/scanner.ts`)が実行足とトレンド足の2種類のOHLCVを取得し、**それぞれ最後の1本(未確定足)を除いた確定足のみ**で判定します。
- RSIはWilder方式、EMAは標準的な指数平滑方式(いずれも `src/indicators.ts`)。
- 出来高倍率は「直近確定足の出来高」÷「その直前N本の平均出来高」。
- RSI・出来高・陽線・トレンドフィルタの4条件がすべて揃った取引所に対して、`ALERT_COOLDOWN_SEC` で再通知を抑制しつつDiscord/Telegramへ通知します。

## 注意事項

- これはシグナルの検知・通知のみを行うbotで、**自動発注は行いません**。市場データ(OHLCV)の取得はKYC・口座開設不要な公開APIのみを使用しています。
- デフォルト取引所のMEXCは、日本のFSA(金融庁)から無登録の暗号資産交換業・デリバティブ勧誘について警告を受けている海外取引所です。本botでの利用は公開マーケットデータの監視・通知にとどめてください。実際にMEXC(または他の無登録海外取引所)でレバレッジ・先物のポジションを取ることは、FSA登録業者を利用する場合に比べて法的保護(ADR・裁判所の利用者保護など)が及ばないリスクがあるため、各自の判断と責任で検討してください。
- 取引は自己責任です。本botの通知は投資助言ではありません。
