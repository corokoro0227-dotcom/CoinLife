# コピートレード スクリーニングツール

MEXCなどのコピートレードで「誰をフォローするか」を、見た目のROIではなく客観的なリスク指標で機械的に評価するための手入力ツールです。

## なぜ自動取得ではなく手入力なのか

MEXCの公式Futures APIドキュメント([mexcdevelop.github.io](https://mexcdevelop.github.io/apidocs/contract_v1_en/))には、コピートレードのトレーダーランキング/成績を取得できる公開エンドポイントが存在しません。ドキュメント化されているのは市場データ・口座・注文まわりのみです(`bots/rsi-volume-scanner`が使っているのと同じ範囲)。

そのため、コピートレードのデータを自動取得するには非公開・非ドキュメント化された内部APIを推測して叩く(スクレイピング)しかなく、これは規約違反のリスクや仕様変更で壊れるリスクがあるため採用していません。代わりに、あなたがMEXCの画面で見た数値を入力する方式にしています。

## 使い方

1. `traders.example.json` をコピーして `traders.json` を作る
2. MEXCのコピートレード画面(トレーダー詳細)で見られる数値を埋める:
   - `trackRecordDays`: トレーダーとして稼働している日数
   - `roi7dPct` / `winRate7dPct` / `tradesPerWeek`: 直近7日のROI・勝率・取引頻度
   - `maxDrawdownPct`: 最大ドローダウン(表示されていれば必ず入力。最重要指標)
   - `profitShareRatio`: 利益分配率(%)
   - `followerCount` / `aumUsdt`: フォロワー数・運用資産規模
   - `typicalLeverage`: 常用レバレッジ倍率
   - 不明な項目は `null` のままでOK(未入力として保守的に評価される)
3. 実行:

```bash
node score.mjs traders.json
```

## 評価方針

「ROIが高い=優秀」ではなく、**生存バイアスにだまされないこと**を優先した重み付けにしています。

| 指標 | 重み | 考え方 |
|---|---|---|
| 稼働日数 | 25 | 短期間の好成績は複数の相場局面を経験していない。1年でフルスコア |
| 最大ドローダウン | 25 | 最重要のリスク指標。**未入力は高リスク扱い(0点)**にする |
| 勝率 | 15 | 高いほど良いが、95%以上は逆に「母数が少ない/都合よく見せている」可能性としてフラグを立てる |
| 取引頻度 | 10 | 極端に少ない(休眠)/極端に多い(過剰トレード)の両方を減点 |
| 利益分配率 | 10 | 低いほどコストが少ない |
| 常用レバレッジ | 15 | 高レバレッジほど強制清算リスクが上がるため減点 |

スコアが低い/フラグが多いトレーダーを機械的に除外するのではなく、**なぜ低いのかを説明するための道具**として使ってください。

## 注意事項

- これは投資助言ではありません。過去の入力データに基づく参考スコアであり、将来の成績を保証しません
- コピートレードは元のトレーダーの損失をそのまま引き継ぐ仕組みです。スコアが高くても資産の一部のみで試す、複数トレーダーに分散するなどのリスク管理を推奨します
- MEXCは日本のFSAから無登録デリバティブ勧誘について警告を受けている海外取引所です。実際に利用する場合は`bots/rsi-volume-scanner/README.md`の注意事項も参照してください
